What is a harness?

Prompt

A reusable instruction. Copy it.

Plugin

A reusable tool. Call it.

Harness

A reusable implementation. Depend on it, fork it, compose it.

Skill

A reusable business capability. Enable it.

A skill is built on exactly one harness; many skills may share one. That sharing is the point.
