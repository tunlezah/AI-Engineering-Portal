A reference architecture is a documented pattern: when to use it, when not to,
what it costs you, which plugin classes it needs, and which evaluation metrics
actually matter for it. Each blueprint lists the harnesses that implement it,
so the path from "I need a RAG system" to "here are three, one is certified"
is one click.

Every harness declares **exactly one** pattern. Multiple patterns per harness
would make this facet useless; genuine departures are declared as deviations on
the harness page instead.
