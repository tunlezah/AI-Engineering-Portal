# Quick Start

> This document is **executable**. The `harness:smoke` CI job runs every fenced
> block tagged `shell exec` and asserts the expected output. If the docs drift
> from reality, the pipeline goes red. Do not edit this file without running it.

**Time:** ~10 minutes · **Prerequisites:** membership of `group:legal-ai-platform`,
`harnessctl >= 1.8`, network access to the internal model gateway.

## 1. Clone and install

```shell exec
git clone https://gitlab.acme.internal/ai-platform/harnesses/legal/contract-review
cd contract-review
harnessctl install --lockfile harness.lock
```

`install` resolves the three required plugins and two composed harnesses from
`harness.lock`. It never reaches the internet; all artefacts come from the
internal package registry.

Expected tail:

```
resolved 3 plugins, 2 harnesses
  document-parser        3.4.1  (core)
  legal-playbook-search  1.6.3  (certified)
  pii-redactor           2.1.0  (core)
  document-segmentation  4.1.2
  citation-grounding     2.2.4
environment ready
```

## 2. Verify the environment

```shell exec
harnessctl doctor
```

This checks model gateway reachability, plugin health, index availability
(`legal-playbook-v7`) and that no credential is being sourced from the repo.
Any `FAIL` line here means the run in step 3 will not work — fix it first.

## 3. Run against the bundled sample

The sample contract is synthetic and safe to use. Real contracts are
`confidential`; do not place them in a working copy.

```shell exec
harnessctl run \
  --input contract_file=examples/sample-msa.pdf \
  --input playbook_id=uk-standard \
  --input counterparty_tier=tier-2 \
  --config config/default.yaml \
  --out ./out
```

Expected summary line (asserted by CI within tolerance):

```
run complete: 11 findings (2 high, 3 medium, 1 review-required, 5 info)
coverage 0.86 · grounded 11/11 · cost £0.39 · 71s
awaiting sign-off: queue legal-review
```

## 4. Read the findings

```shell exec
harnessctl explain ./out/findings.json --format table
```

```
SEV     ANCHOR    POSITION    DIVERGENCE
high    p12/¶3    PB-IP-004   Uncapped IP indemnity, carved out of the general cap
high    p24/¶2    PB-TRM-002  One-sided termination for convenience, 30d notice
medium  p18/¶1    PB-AUD-003  Audit rights limited to once per 24 months
...
```

Every row is click-through: `harnessctl explain --anchor p12/¶3` prints the
quoted evidence, the retrieved playbook position and the citation chain.

## 5. Inspect the audit record

```shell exec
harnessctl audit ./out/audit_record.json
```

Shows prompt versions, model build, retrieved document ids and each guardrail
decision. This is what an auditor asks for; it is produced on every run, not
only when someone remembers to enable it.

## 6. Try it from a skill

```shell exec
harnessctl simulate-skill contract-triage --harness . --input examples/sample-msa.pdf
```

Runs the harness through the calling contract that `skill://contract-triage`
uses, so you can see exactly what the skill will receive.
